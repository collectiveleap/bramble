The Blend Engine

A durable core shaped for the hardest case, driven by a fixed line of operations — where frames enter either pre-supposed by goal or recruited from the flow, and a moving run shows exactly which.

Stance · hybrid — mechanical kernel + cognitive core Grounded in · Fauconnier & Turner Date · 2026-08-12

§1 The durable core: the blend-state

One run builds one blend-state, shaped to hold a full four-network so expanding coverage never reshapes it. Simplex populates only a corner; double-scope fills the rest of the same slots.

Input spaces core

One or more. Each carries an optional frame (its roles), its elements (role-bindings if framed, raw values if not — stamped with provenance and time), and its source provenance. The frame slot also carries a frame-provenance: pre-supposed (brought by the goal) or recruited (pulled from content by completion). One shape covers frame-only, value-only, and fully-framed instance.

Generic space core

The shared skeleton abstracted from the inputs, licensing the mapping. Trivial for simplex; genuinely abstracted for double-scope.

Cross-space mappings core

Counterpart links across inputs, each tagged identity / analogy / role-value / change.

Blended space core

Projections, emergent structure (tagged composition / completion / elaboration), organizing frame(s) (one → simplex/mirror, two → double-scope), and clashes (value and frame), each with resolution or held-tension, rationale, and strategy.

Residue core

Elements that filled no role, classified by reason: an anomaly (a missing-frame signal — meaningful content no recruited frame organizes, which loops back to recruit-frame and, if that misses, is parked as an open FrameCandidate) or noise (unframable, discarded). anomaly is adopted from Klein's Data/Frame sensemaking — a marked cross-domain term, layered onto CB's completion.

Network type derived label

Read off the organizing-frame count; emitted, never input.

§2 The operation catalog

Each operation is a stable signature over the blend-state. The mech form is deterministic and auditable; the cog form is the cognitive core behind the same interface. Simplex v1 implements only the mechanical forms.

§3 The architecture

An orchestration runs a fixed line of operations; all read and write the one blend-state beneath. The bar under each operation marks its determinism — deterministic (fully mechanical, reproducible), combination (a deterministic default with a non-deterministic cognitive escalation), or the tunable seam (resolve, spanning the whole range by strategy). Frames enter through two doors — pre-supposed into add-input, or recruited at recruit-frame — and residue loops back to recruit a new frame when a pre-supposed one leaves something unplaced.
