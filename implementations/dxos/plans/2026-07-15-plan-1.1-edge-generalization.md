# Phase 1.1 — Edge generalization (`Node` → `Obj.Unknown`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generalize the Bramble `Edge` relation so its endpoints are *any ECHO object* (`Obj.Unknown`), not only the plugin's own `Node` — the substrate foundation for BR-16 (a node = a role any object plays, `Edge` = the only foundational schema).

**Architecture:** One schema edit (`Edge` relation endpoints `Node` → `Obj.Unknown`) plus widening the two low-level edge constructors and the linked-edge model creator to accept `Obj.Any`. Traversal is provably id/kind-only, so it needs no logic change. The `as Node` casts in `tryGetTarget`/`tryGetSource` and the `Node`-typed traversal signatures are **left as-is** — they are a harmless render-boundary narrowing (every rendered endpoint is still a `Node` today) and are dropped in **Phase 1.3 (heterogeneous render)**, where dispatching on type gives them a reason to exist. This keeps 1.1 a minimal, low-risk substrate increment.

**Tech Stack:** TypeScript (strict), `@dxos/echo` (`Type.makeRelation`, `Obj.Unknown`, `Obj.Any`, `Relation`), `@dxos/echo-client/testing` (`EchoTestBuilder`), `@dxos/schema` (`Text`), Vitest, `moon` task runner.

Both tasks landed (commits `788ea1937e`, `dd0d9194f8`); gate green (70/70 tests, storybook 22, lint, build).

the tests are green before *and* after the change. Root cause (a real finding, not a mistake in the code): the
plugin's `Node` declares only an optional `text?` field, so structurally `Node ≈ Obj.Unknown` and every ECHO
object already satisfies a `Node`-typed slot; and ECHO relations resolve endpoints by identity regardless of the
declared type. So the endpoint widening is **declaratively correct + foundational but not runtime-observable** —
no red→green is available. The added tests are kept as **green-on-both-sides regression/documentation** of the
mixed-endpoint capability; the change itself is verified by the schema now declaring `Obj.Unknown` + the green
gate. (Finding recorded in `design-object-graph.md` §2; it affirms BR-16 and D2/schema A.)
